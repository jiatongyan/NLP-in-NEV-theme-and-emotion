# 新能源汽车在线评论主题情感分析（NEV Topic Sentiment Analysis）

基于 **SnowNLP + LDA + 机器学习** 的新能源汽车在线评论主题情感分析项目，通过挖掘消费者评论中的主题与情绪之间的关系，为新能源汽车品牌竞争情报分析提供支持。

---

## 项目简介

本项目以 **特斯拉（Tesla）** 和 **比亚迪（BYD）** 两个新能源汽车品牌的在线评论为研究对象，围绕评论文本展开 **情感分析、主题挖掘以及主题-情感关联分析**，探索新能源汽车领域消费者关注的核心竞争痛点。

项目不仅实现了评论情感分类和主题识别，还进一步量化了不同主题对情感类型的影响程度，并引入 **情感极端性（Sentiment Extremity）** 作为新的分析维度，从而更深入地挖掘评论中的竞争情报。

---

## 研究背景

### 研究目的

新能源汽车市场竞争日趋激烈，消费者在线评论中蕴含着大量关于产品、技术、服务等方面的竞争信息。本项目旨在：

* 提炼新能源汽车消费者关注的核心主题；
* 分析不同主题对应的情感倾向；
* 挖掘品牌竞争优势与竞争痛点；
* 为竞争情报分析提供数据支持。

### 研究方法

项目整体采用以下技术路线：

1. **数据采集**：爬取新能源汽车品牌在线评论；
2. **文本预处理**：中文分词、停用词处理；
3. **情感分析**：基于 SnowNLP 获取评论情感得分；
4. **主题挖掘**：使用 LDA（Latent Dirichlet Allocation）模型提取评论主题；
5. **主题情感关联分析**：利用机器学习算法量化主题对情感的影响程度。

## 核心功能

### 一、数据爬取（Web Crawling）

项目提供了 **两种不同平台的评论采集方式**，可根据目标平台选择对应爬虫程序。

功能包括：

* 评论抓取
* 分页采集
* 数据存储
* 字段清洗

---

### 二、文本预处理（Text Preprocessing）

对原始评论进行标准化处理，包括：

* 中文分词
* 去除停用词
* 文本清洗
* 构建词袋模型

项目已提供：

* 停用词词典
* 完整预处理代码

---

### 三、情感分析（Sentiment Analysis）

基于 **SnowNLP** 开源工具进行中文情感分析。

输出包括：

* 情感得分（0~1）
* 情感类别（积极 / 消极）
* 评论情绪统计

SnowNLP 适用于中文短文本情感分析，能够快速完成评论情感标注。

---

### 四、主题挖掘（Topic Modeling）

使用 **LDA（Latent Dirichlet Allocation）模型** 提取评论主题。

项目包含：

* LDA 建模代码
* 主题关键词输出
* 主题解释分析
* 可视化分析

此外，还提供了 **两种主题数量选择方法**：

* **Perplexity（困惑度）**
* **Coherence（一致性）**

可结合两者共同确定最优主题数量。

---

### 五、关键主题分析（Topic-Sentiment Association）

这是本项目的核心部分。

在获得评论主题和情感标签后，使用 **机器学习算法** 建立主题与情感之间的关系，量化：

* 不同主题对积极情绪的影响
* 不同主题对消极情绪的影响
* 最容易产生情绪极端性的主题

最终识别出 **关键竞争主题（Key Competitive Topics）**。

## 研究结果

主要结论如下：

* **特斯拉与比亚迪吸引消费者的优势不同；**
* **两个品牌面临的核心问题存在明显差异；**
* 在涉及 **技术主题** 的评论中，

  * 特斯拉与比亚迪表现出 **相反的情感极端性特征**；
* 不同主题对评论情绪具有显著影响，可作为竞争情报的重要来源。

* **主题 + 情感联合分析**
* **量化主题对情绪的影响程度**
* **引入情感极端性（Sentiment Extremity）**
* **结合机器学习建立主题-情感映射关系**
* **适用于新能源汽车竞争情报分析**
